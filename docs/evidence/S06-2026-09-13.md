# S06 · Hardening, performance и security · 2026-09-13

Проверялось рабочее дерево после S05 `2fbfe82`, production MV3 builds. Среда: macOS arm64,
Node 24.13.0, pnpm 10.29.2, Chrome for Testing 153.0.8010.12, Firefox 155.0.1.
Synthetic fixtures и браузерные профили были временными.

## Реализация и найденный дефект

- Runtime guards теперь принимают только объявленные protocol types/reasons, safe integer frame
  IDs и bounded identity strings. Persisted session state проходит те же exact target/ancestor
  guards; object-toString coercion, неизвестные error codes, отрицательные tab IDs и чрезмерные
  numeric/string payloads отклоняются.
- S06 security E2E проверяет page `postMessage`, поддельный `FRAME_BIND`, content-origin
  `SET_ENABLED`, malformed own-extension messages и отсутствие capability в MAIN world.
- Performance E2E измеряет OFF mutation storm, активную сессию под нагрузкой, 100 ON/OFF циклов
  и DOM из 25 100 элементов. Счётчики покрывают MutationObserver, IntersectionObserver,
  timers, TreeWalker и Long Tasks в isolated world.
- Full restart gate обнаружил реальный дефект: при пустой после рестарта `storage.session` эффект
  был OFF, но tab-specific action title оставался базовым `AntiMirror`. Startup recovery теперь
  выставляет явный OFF для вкладок без активной сессии. Сохранённые ON-состояния не показываются
  до адресной reconciliation и ACK. Повторный restart gate прошёл.

## Performance evidence

- 100 циклов: ON p95 41.30 ms при цели ≤500 ms; OFF p95 8.30 ms при цели ≤200 ms.
- Во время активного сценария максимум instrumentation: 2 MutationObserver, 1
  IntersectionObserver, 3 timers. После каждого OFF и в конце: 0 observers, 0 IO, 0 timers,
  ровно 0 owned animations.
- OFF mutation storm (400 nodes/s): 0 observers, 0 IO, 0 timers, 0 TreeWalker visits.
- Большой DOM: 103.62 ms, 25 001 инструментированный вызов TreeWalker (25 000 protocol visits
  плюс terminal call), incomplete result, cleanup baseline. Long Tasks API доступен;
  максимальный зарегистрированный long task 0 ms при лимите <50 ms.
- Existing S02/S03 regression подтвердил per-document 25k, per-tab 100k, 64-frame/4-scan/3s
  budgets, bounded frame coverage и cleanup всех discovery/frame ресурсов.

## Security, privacy и release artifact review

Отдельный review pass по checklist `antimirror-review` сопоставил trusted activation,
background-only state writer, `tabId + documentNonce + operationId + targetId`, ancestor bindings,
cleanup ownership и generated manifests. Критических и высоких незакрытых дефектов не найдено.
Review выполнялся отдельно от implementation pass тем же агентом; второй агент не привлекался.

Поиск в `entrypoints`/`src` не нашёл app logging, `fetch`, XHR, WebSocket, sendBeacon, eval,
Function constructor, innerHTML, `storage.local` или cookies API. Production trees не содержат
localhost/test endpoints, source maps, PEM/key files или externally_connectable. Сгенерированный
WXT runtime содержит неисполняемые logging wrappers фреймворка; прикладных log sites нет.
Permissions остались `storage`, `webNavigation`, `scripting` и HTTP(S) hosts; каждый permission
используется текущим runtime. Все package dependencies — development dependencies.

## Покрытие и gaps

T01–T05, T08–T56 и T60–T68 покрыты unit/production Chromium/Firefox gates в объёме их
канонических сценариев; browser-specific unsupported cases возвращают документированный OFF.
T60–T62 и T66–T68 получили отдельный S06 automation. T70 PASS по production artifact review.

Firefox natural event-page idle остаётся `NOT_RUN`: native harness подтверждает session
roundtrip, но не умеет достоверно принудить и доказать естественный idle. Firefox manual
toolbar/fullscreen/RU UI также `NOT_RUN`; пользователь явно разрешил пропустить недоступную
Firefox-проверку. Edge/Brave, screen-reader smoke и дополнительные реальные видеосайты не
проверялись в S06. Эти gaps не записаны как PASS и переходят в release-candidate smoke S07.

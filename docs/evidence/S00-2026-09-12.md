## Review и ограничения

Проверены новые исходники и diff: production не вызывает discovery, не создаёт Animation,
observers или polling; runtime DOM находится внутри main(ctx). Listener background регистрируется
синхронно. Root adapter не патчит attachShadow. Effect не пишет style/transform/animations сайта,
не трогает host/frame, cleanup отменяет только собственный Animation.
Обработчик SPIKE_APPLY и доступ к synthetic fixture существуют только в отдельной тестовой сборке.

Playwright держал worker живым при 40s ожидании: это **не** PASS natural idle. Поэтому написан
отдельный raw-CDP harness, прикрепляющийся только к probe page. Первые raw-CDP попытки выбрали
встроенный background Chromium; исправлено точным ID, вычисленным из пути нашего addon.
После исправления естественная остановка и recovery подтверждены без mocks.

Сборочные замечания устранены: конфигурация WXT использует объект, probe файлы разнесены по
entrypoint folder, generated outputs исключены из lint; Firefox декларирует отсутствие сбора данных.
Firefox 140 — выбранный manifest minimum, фактически проверены версии 150.0.1 и 155.0.1.

NOT_RUN: Firefox event-page idle/recovery, VK и другие реальные сайты, native controls/captions,
fullscreen/PiP, Edge/Brave и полный production lifecycle/controller. Они не объявлены PASS.
Сложные CSS conflicts ещё не диагностируются primitive: TD01, закрыть перед production ON.
S00 не реализует пользовательскую активацию и не подтверждает поддержку реальных видеоплатформ.

Источники уточнений: [WXT browser targeting](https://wxt.dev/guide/essentials/target-different-browsers),
[Playwright extensions](https://playwright.dev/docs/chrome-extensions),
[Firefox data consent](https://extensionworkshop.com/documentation/develop/firefox-builtin-data-consent/).

Следующий шаг: S01 — popup intent → background → адресный apply/ACK → ON/OFF для одного top video.

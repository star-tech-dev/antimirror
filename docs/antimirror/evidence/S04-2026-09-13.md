## Реализация

- Target media snapshot до PREPARE; source mutations, emptied/loadstart/error/ended,
  connection loss и отмена собственного Animation снимают эффект локально до отправки report.
  Watchdog выбранного video ≤1 Hz, без background messages в healthy path; hidden polling
  приостановлен. Pause/waiting/stalled/seeking/timeupdate и sync reparent сохраняют ON.
- pagehide очищает owned sessions и сохраняет пассивный dispatcher; старые операции tombstoned.
  Новое ручное включение после настоящего BFCache работает. Navigation reports имеют точную причину.
- History/hash events сравнивают session-only SHA-256 URL fingerprints через commit fences.
  Same URL сохраняет ON. Native navigation, discard, replace/remove обрабатываются отдельно.
- TargetRef записан до PREPARE. Wake/UI reconciliation проверяет top nonce/URL, exact target
  tuple, COMMITTED и committed ancestor watchers. Нет discovery или повторного COMMIT при recovery.
- OFF атомарно сохраняет pending cleanup identity в native session; недоставленный CANCEL
  повторяется при следующем взаимодействии/wake, до нового включения. Удалённый native frame
  подтверждает отсутствие старого документа. Storage-init failure не выдаётся за пустой OFF.
- Новый user intent защищён от позднего APPLIED и поздней ошибки старой операции;
  action writes остаются последовательно упорядоченными.

## Найденное при проверке

1. Popup мог показать устаревший ON между page-cancelled animation и watchdog; адресный
   GET_STATE reconciliation закрывает эту гонку.
2. pagehide выбранного iframe мог дать TARGET_LOST раньше navigation event; report теперь
   сохраняет NAVIGATION без ослабления identity guard.
3. Chromium 153 macOS падал с SIGSEGV при tabs.discard с Playwright-attached renderer,
   как с BFCache, так и в отдельном профиле без него. Raw CDP без attachment к целевой странице
   прошёл реальный discard. Production код и permissions ради этого не менялись.
4. BFCache не испускает новый load; harness ожидает navigation commit и проверяет persisted.

# S09 · PiP state retention · 2026-09-13

Release artifacts are built from implementation commit
`129921a6012f6d48de6c79cc07980651094f4b4b`.

## Implementation

- `watchTargetSession` no longer treats `enterpictureinpicture` as target loss. Visibility
  changes still validate connectivity, media identity and owned effect, while the expensive
  periodic check stays suspended for hidden documents.
- `PIP_UNSUPPORTED` was removed from accepted `TARGET_LOST` reasons. It remains an OFF reason
  only so an older session record can still be rendered safely after an update.
- Product, state, compatibility, test and store copy now promise state retention for the same
  DOM video without promising that the native PiP surface itself is mirrored.

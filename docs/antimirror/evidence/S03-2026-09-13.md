## Изменения

- FrameCoordinator использует native frame tree и адресные PROBE/DISCOVER. Ручной fallback
  загружает тот же passive agent только после отсутствующего ответа конкретного документа.
- Concurrency=4, frames=64, visits/document=25k, visits/tab=100k. Element allowance резервируется
  до запуска scan, unused возвращается после ответа. Общий поиск ограничен 3s; новые frames
  участвуют только внутри текущей попытки. Очередные фазы пустых документов около 0/500/1500 ms.
- Content CANDIDATES содержит bounded visits/frameCount, capabilities и geometry, без URL/HTML.
  Background ранжирует кандидатов всей вкладки; PREPARE_APPLY получает ровно один frame/video.
- BIND_CHILD/EMIT_BIND/READ_BIND сопоставляют token с настоящим source WindowProxy и iframe
  среди найденных DOM refs. Page channel не принимает enable/disable. Parent geometry проверяет
  видимость и fullscreen embedding chain; iframe и host не отражаются.
- WATCH_CHILD/COMMIT_WATCH подтверждают выбранную цепочку. До commit lease=5s; каждая фаза
  установки/commit всей watcher-цепочки ограничена 1s. Parent removal report проверяется по
  runtime tab/frame + documentNonce/operation/token. Снятие эффекта не зависит от отчёта child.
- CANCEL очищает все touched frames; RELEASE_DISCOVERY удаляет losers/невыбранные binds.
  Старый cancel не затрагивает новую операцию; cancelled operations имеют bounded tombstones.
- Navigation выбранного frame/предка и host permission removal сбрасывают состояние; unrelated
  ad navigation/removal сохраняет ON. Ancestor identities сохраняются в native session state.

frameCount coverage check. Late-frame warning теперь пересчитывается после успешного probe,

required permissions; проверка переведена на реальный site-access control тестового профиля.

iframe.contentDocument, захвата медиа, расширения permissions или keepalive background.

## Popup language

The header has an accessible EN/RU selector. The choice is stored as the standalone
`popupLocale` preference in `storage.local`; changing it only reloads local message catalogs and
rerenders the last background-owned state. It never sends `SET_ENABLED` or starts discovery.

Chromium production E2E verified EN → RU, persistence after closing/reopening the popup and RU →
EN while state stayed OFF. Firefox native UX regression passed with the new add-on ID. Manual
Firefox toolbar UI remains `NOT_RUN` under the previously accepted skip.

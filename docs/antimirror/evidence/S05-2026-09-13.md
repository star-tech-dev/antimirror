# S05 · UX, hotkey и renderer compatibility · 2026-09-13

Реализация после S04 `3b26990`; проверялось рабочее дерево S05, production MV3 builds.
macOS arm64, Node 24.13.0, pnpm 10.29.2, Chrome for Testing 153.0.8010.12,
Firefox 155.0.1. Synthetic fixtures запускались на временных портах и профилях.

## Реализация

- Popup оставляет одну основную toggle-control, сообщает searching/applying только до ACK,
  использует `aria-live`, `aria-pressed`, focus-visible и фактическое значение browser command.
  Если command не назначен, popup прямо отправляет пользователя в настройки shortcuts.
- Native `_locales/en` и `_locales/ru` покрывают manifest, состояния, причины, warnings,
  кнопки и shortcut. Generated manifests имеют `default_locale: en`; обе locale-папки входят
  в Chrome и Firefox builds.
- `commands.onCommand` регистрируется синхронно при старте background. Только точное имя
  `toggle-mirror` переключает активную вкладку через тот же `TabController`; открытие popup,
  page messages и content events не становятся trusted activation.
- Media source/reset, ended/error, PiP, потеря собственного Animation и отзыв permissions
  получили разные protocol reasons и разные пользовательские строки. Runtime guard принимает
  только объявленный набор reasons.
- Additive WAAPI flip не меняет `style`, `transform-origin` и `backface-visibility`; current
  site style переживает OFF. `transform!important` и несовместимый native fullscreen дают
  безопасный `TRANSFORM_CONFLICT`. PiP снимает сессию с `PIP_UNSUPPORTED`.

## Review и gaps

Diff review preserved one target per manually activated tab, background-only state writes,
exact document/operation/target fences, session-only enabled state, reversible style ownership,
OFF resource cleanup and the absence of page-controlled activation. No remote push/publication.

The Firefox production Selenium gate passed, but Computer Use could not attach to the isolated
headed Firefox window (`timeoutReached`). Therefore Firefox toolbar shortcut/popup, native
fullscreen controls and native RU UI remain `NOT_RUN`; S05 stays `IN_PROGRESS`. TD03 remains
open only for that Firefox/manual verification boundary. The next run should close those gates
without changing production behavior unless they reveal a defect.

# 06. Релиз и публикация

## Gate готовности

Расширение не считается готовым по факту успешного `wxt build`. Перед release candidate:

- Слайсы S00–S06 завершены, evidence заполнен, нет критических bugs с ложным ON, самовключением,
  утечками DOM/animations, навигационными гонками и изменением чужих элементов.
- Chrome и Firefox MV3 builds проверены отдельно. Chromium-compatible browsers имеют отдельный
  smoke-статус. Версии и минимальные browser requirements основаны на реальных прогонах.
- VK Видео проверен в доступном реальном сценарии либо явным образом НЕ заявлен как проверенный.
- Native controls, PiP, closed roots и permissions не описаны шире фактически подтверждённого.
- Production артефакт не включает тестовый стенд, e2e harness, test commands, отладочные страницы,
  sourcemaps с секретами, локальные absolute paths, telemetry или remote code.
- ON/OFF icons различаются не только цветом; PNG sizes соответствуют action/manifest;
  имена и locale strings корректны. Нет заимствованных без разрешения брендовых логотипов.
- Нажатие на action с popup не пытается параллельно включать через action.onClicked.

## Подготовка артефактов

Создать release zip для Chromium и отдельный Firefox package/source archive в формате,
который нужен актуальному процессу магазина. Проверить действующие правила непосредственно
перед загрузкой, а не считать этот документ вечной инструкцией по store submission.

Для reproducibility зафиксировать commit, lockfile, Node/pnpm, команды, SHA256 артефактов.
Проверить исходный source package: reviewer должен суметь воспроизвести сборку без секретов.

Существующий LICENSE сохранить. Если его нет, выбрать лицензию должен владелец до публичной
публикации; агент не должен сам выдавать проект под MIT/GPL. Это не блокирует локальную
реализацию. Не придумывать store ID, gecko ID, support email, сайт политики и имя legal entity.

## Безопасное позиционирование

Предлагаемое краткое содержание карточки после подтверждения функций:

> Отражайте видео по горизонтали одним действием. Отдельное включение для каждой вкладки,
> поиск плееров во вложенных структурах страницы и автоматическое выключение при смене видео
> или переходе на другую страницу. Обработка выполняется локально.

Эта формулировка — основа, не утверждение текущей готовности пакета. Для фразы «при смене видео»
обязательно раскрыть наблюдаемые признаки и ограничение same-MSE/same-URL в подробном описании.
Не писать «работает везде», «полная поддержка PiP» или «обход авторских прав/Content ID».

## Privacy policy — содержание для финализации

В политике правдиво отразить: расширение меняет отображение выбранного HTMLVideoElement;
не скачивает и не передаёт видео; не анализирует изображение и звук; не содержит аналитики;
временное состояние вкладки хранится локально на время браузерной сессии; доступ к сайтам
необходим для выполнения действия в обычных и вложенных плеерах.

Если в коде появится любое новое сетевое взаимодействие/данные/диагностика, сначала обновить
privacy inventory и решение об объёме продукта, затем policy и store declarations.
Фраза «ничего не собираем» не освобождает от точного описания локальной обработки URL/metadata.

## Объяснение permissions для reviewer

HTTP/HTTPS hosts — работа с явно выбранным видео на произвольном сайте, включая сторонние
embedded players. `webNavigation` — прекращение действия на новом URL/документе.
`storage` — согласованное per-tab session state при приостановке background.
`scripting` — ручной запуск на вкладке, открытой до установки агента.
Каждое разрешение должно реально использоваться; удалить лишнее.
Основание: [S21](08_SOURCES.md#s21).

## Действия владельца перед публикацией

Подтвердить название и лицензию; предоставить действующие store/developer реквизиты и contact
для поддержки; принять окончательное описание/privacy policy; явно поручить публикацию.
Агент может подготовить артефакты и отчёт, но не публикует автоматически.

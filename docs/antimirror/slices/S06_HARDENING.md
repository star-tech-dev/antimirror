# S06. Надёжность, производительность и безопасность

**Зависимость:** S05. **Effort:** High. **Начальный статус:** TODO.

## Цель

Пройти полный regression, performance/cancellation stress и независимый security/ownership
review. Убрать утечки, шумные логи, лишние permissions и тестовую инфраструктуру из release build.

## Работа

Измерить OFF/ON отдельно от нагрузки страницы, 100 циклов, большой DOM и frames,
worst-case таймауты, permission failures, обновление context. Сопоставить фактический
протокол, инструкции, архитектуру и слайсы, убрав документальные противоречия.

## Definition of Done

Нет критических/высоких незакрытых дефектов в инвариантах. Бюджеты измерены, cleanup
возвращает baseline. Отчёт содержит реально выполненные браузеры и NOT_RUN проверки;
независимое review не подменяет evidence.

## Проверки

Все T01–T70 с акцентом T43–T56, T60–T68, плюс production manifest/artifact inspection.
Chromium automation и настоящая Firefox extension проверка учитываются раздельно.

Канонические сценарии: [05_TEST_PLAN](../05_TEST_PLAN.md).
Все результаты фиксировать в evidence; NOT_RUN не равен PASS.

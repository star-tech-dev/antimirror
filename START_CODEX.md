# Первый запуск Codex

Прочитай AGENTS.md и документацию в docs/antimirror. Это канонический пакет для реализации
АнтиЗеркало / AntiMirror: WXT, TypeScript, vanilla UI (or vuejs), desktop Manifest V3.

Сначала изучи существующий репозиторий и инструкции. Если проект уже частично реализован,
сопоставь его с новым ТЗ, сохрани полезное и мои незакоммиченные изменения; не запускай
генератор поверх существующих файлов. Старые allowlist, автозапуск и глобальное включение
не относятся к новой v1. Не наследуй их случайно. Существующую лицензию не меняй.

Выполни S00 по docs/antimirror/slices/S00_FOUNDATION.md, используя
.agents/skills/antimirror-implement-slice/SKILL.md. Создай недостающий минимальный каркас,
зафиксируй инструменты и выполни браузерные feasibility-проверки, предусмотренные слайсом.
Не ограничивайся планом. Если конкретного браузера или инструмента нет, выполни доступные
части, явно отметь непроверенное и не подменяй браузерный результат моками.

Разработка дальше идёт по восьми слайсам. Поддерживай progress, handoff, техдолг и инструкции
в актуальном состоянии. Не раздувай архитектуру и не добавляй функции вне v1.

В конце покажи реализованное, результаты проверок, оставшиеся блокеры и точный следующий шаг.
Публикацию в магазинах и отправку изменений в remote не выполняй.

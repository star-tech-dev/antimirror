# AntiMirror — Отразить видео

## Краткое описание · не более 132 символов

Исправляет зеркальное видео во вкладке — локально, вручную и без отражения элементов плеера.

## Полное описание

Исправьте зеркальное HTML5-видео одним осознанным действием. AntiMirror отражает только одно
основное видео в активной вкладке, оставляя на месте кнопки, субтитры, элементы управления и разметку страницы.

- Ручное включение и выключение отдельно для каждой вкладки
- Поиск видео в доступных встроенных плеерах и web components
- Привязка к выбранному видео до смены страницы или медиаресурса
- Настраиваемое сочетание клавиш и переключатель EN/RU в popup
- Полностью локальная работа без аналитики, аккаунтов и внешнего сервера

AntiMirror подходит для зеркальных записей, видео с веб-камеры, трансляций, занятий и других
HTML5-видео с перевёрнутым по горизонтали изображением. Расширение не скачивает и не записывает
видео, а также не читает кадры. Нативное окно Picture-in-Picture может не показать отражение, но
после возврата на страницу то же видео останется отражённым. Canvas/WebGL-плееры, защищённые
страницы и недоступные iframe могут не поддерживаться.

Откройте расширение, нажмите **Включить**, а для возврата исходного вида — **Выключить**.

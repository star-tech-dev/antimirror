# Changelog

## 1.0.0 — release candidate (2026-09-13)

- Added an explicit EN/RU popup selector with a locally persisted preference.
- Set the stable Firefox ID to `antimirror@star-tech.dev` and support site to `star-tech.dev`.

- Manual per-tab mirroring through a localized popup or browser shortcut.
- One selected video across accessible nested shadow roots and iframe documents.
- Exact document/operation/target ownership with navigation and media lifecycle reset.
- Reversible additive transform that preserves page styles and reports safe conflicts.
- Native MV3 session recovery, bounded discovery and zero active scan resources while OFF.
- Chrome and Firefox production builds with EN/RU localization and distinct ON/OFF icons.
